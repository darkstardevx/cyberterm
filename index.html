Rust wgpu glyphon alacritty_terminal

A terminal, GPU-rendered.

Real PTY handling via alacritty_terminal, real glyph rendering via glyphon (cosmic-text + etagere on a wgpu pipeline). 12 built-in Kitty-format themes, a live in-terminal theme menu — no Electron, no bundled shell.

GPU rendering

Glyphs on the GPU.
Backgrounds on the GPU.

Text is drawn by glyphon (cosmic-text shaping + etagere glyph atlas) on a wgpu render pipeline. Per-cell background color — selection highlights, an ls --color entry — is a separate hand-rolled quad pass, since glyphon only rasterizes glyphs.

Window opacity fades cell backgrounds only; text stays fully opaque, matching how Ghostty/Kitty/Alacritty do transparency.

cyberterm
opacity
$ cyberterm +set-opacity --custom=0.85

window opacity saved: 0.85
cell backgrounds fade, text stays opaque
Real Kitty theme syntax

12 built-in themes.
Any kitty-themes file drops in.

Built-in themes are genuine Kitty .conf syntax — flat, space-separated key value lines. Anything pulled straight from kovidgoyal/kitty-themes works unmodified, no conversion.

Press Ctrl+Shift+T in the terminal to open the theme menu live — switch and preview without restarting.

cyberterm +list-themes
themes
$ cyberterm +list-themes

synthwave_84     dracula_cyber   vaporwave_85
tokyo_grid       gruvbox_cyber   nord_neon
cyberpunk_2077   darcula_glow    toxic_waste

$ cyberterm +set-theme vaporwave_85
saved as default theme

Get cyberterm running

One command — downloads, verifies the checksum, installs to ~/.local/bin.

>_ curl -fsSL https://raw.githubusercontent.com/darkstardevx/cyberterm/main/install.sh | sh

Installs cyberterm. Linux needs the usual desktop GL/X11/Wayland libraries already present.
